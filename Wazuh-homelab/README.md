# 🛡️ Wazuh Homelab

Laboratorio práctico de monitorización y detección de eventos de seguridad utilizando Wazuh.

## 🎯 Objetivo

El objetivo de este proyecto es desplegar un entorno de laboratorio para aprender los fundamentos de:

- Monitorización de sistemas
- Centralización de logs
- Detección de eventos de seguridad
- Análisis de alertas
- Administración de agentes
- Investigación básica de incidentes
