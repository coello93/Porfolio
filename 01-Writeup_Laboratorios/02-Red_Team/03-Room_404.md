**Completa, Dificultad: easy**<br>

Abrimos el navegador con la ip y el puerto que nos han proporcionado, observamos que no podemos acceder a ninguna pagina todas dan el error 404. <br>
<br>
Analizamos la URL con una herramienta de enumeración que se llama **GOBUSTER**<br>
Con el comando: gobuster dir -u http://IP:Puerto/ -w /usr/share/wordlists/SecLists/Discovery/Web-Content/quickhits.txt <br>
<br>
Pero vamos a comprender el comando antes de continuar. <br>
gobuster → Herramienta de enumeración, para descubrir recursos ocultos. <br>
dir → Buscar directorios y archivos web. <br>
-u → Significa que URL. Le indicamos cuál es el objetivo sobre el que debe trabajar. <br>
-w → Significa wordlist que es un archivo de texto que n cada línea contiene una posible ruta. Como ejemplo: admin, login, images, etc. <br>

¿Por qué ha descargado un archivo? Porque no esta encontrando una pagina web, esta encontrando un repositorio de GIT.<br>
El navegador dice no lo puedo mostrar pues lo descargo.<br>
Asique como parece que tenemos varias archivos vamos a descargar el archivo a nUESTRO equipo con el comando.<br>
wget -r -np -R "index.html*" http://10.128.189.87:8080/.git/<br>
wget → Herramienta para descargar archivos desde un servidor web por HTTP o HTTPS. <br>
-r → Indica que descarge esta pagina y los enlaces y los recuros a los que apuntan. <br>
-np → No descarga a los padres, esto significa que lo limitamos. <br>
-R "index.html" → Con esto le indicamos que no nos interesa los archivos que no los guarde. <br>
A continuación ponemos ls para ver los archivos y vemos la "IP" con laque estamos trabajando, entramos dentro de la carpeta. y con ls -la vemos que no esta vacia la carpeta.<br> 
Con que veamos el archivo correcto dentro de esta web es suficiente para sacar la flag, y resolver la maquina. <br>
